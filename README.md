# 자료구조 중간고사 연습실 (필기 · 코딩)

러닝메이트 1학년 자료구조(Python) 중간고사 대비 사이트예요.

**시험 형식이 바뀌었어요.** 프로그래머스 코딩 시험은 연기되고, 중간고사는 **지필 시험(Closed Book · Closed Notebook)** 으로 봐요.
- 최대 1시간 30분, 약 25~30문항
- 범위: 수업 강의 자료 + 교재 「쉽게 배우는 자료구조 with 파이썬」 Ch.1 ~ Ch.6
- 유형: 객관식 · 단답형 · 짧은 서술형 + 실제 자료구조 코드의 일부를 채우는 문제
- 튜터 안내: 알고리즘 복잡도(O · Θ · Ω) 문제와 자료구조 코드 빈칸 문제를 꼭 준비

사이트: https://learningmate-lab.github.io/ds-list-lab/

## 필기 연습 (홈 맨 위)

- **문제 은행 184문항** (Ch.1 14 · Ch.2 24 · Ch.3 40 · Ch.4 20 · Ch.5 50 · Ch.6 36), 유형별 객관식 70 · 단답형 48 · 짧은 서술형 25 · 코드 빈칸 41, 복잡도(O · Θ · Ω) 69
  - 객관식: 보기 4~5개, 보기마다 해설
  - 단답형: 정규화해서 자동 채점 (공백 · 대소문자 · `n²`/`n^2` · `log₂n`/`log n` · `Θ`/`theta` · `1,024번`/`1024` 등)
  - 짧은 서술형: 2~4문장으로 쓰고 → 모범 답안 + 채점 포인트를 보고 **맞음 · 부분 · 틀림**으로 스스로 채점 (AI · 서버 없음)
  - 코드 빈칸: 실습 코드(`LinkedListBasic`, 원형 · 원형 이중 연결 리스트, `ListStack`, `LinkedStack`, `postfix.evaluate`)와 재귀 · 배열 리스트 코드에 빈칸 1~4개. 채점 후 정답 코드 전체를 보여 줌
- **단원별 · 유형별 · 난이도별 연습**, 안 푼 문제 / 오답노트만, 순서대로 / 섞어서
- **필기 모의고사**: 실전 28문항 · 90분 (객관식 12 · 단답형 7 · 코드 빈칸 6 · 짧은 서술형 3 / Ch.1 2 · Ch.2 4 · Ch.3 7 · Ch.4 3 · Ch.5 7 · Ch.6 5, 복잡도 문제 8개 이상), 미니 14문항 · 45분. 시험 중에는 채점 결과를 숨기고, 끝나면 자동 채점 + 서술형 자기 채점 → 점수 · 단원별 · 유형별 결과 · 오답노트
- **오답노트**: 틀리거나 부분 정답인 문제가 자동으로 모이고, 다시 맞히면 “다시 맞힘”으로 바뀜. 기록은 이 브라우저(localStorage)에만 저장
- 개념 정리의 📝 **시험 포인트**는 필기 시험 기준(점근 표기 정의 · 점화식 · 외워서 쓸 코드), 💻 코딩 연습 포인트는 코딩 문제용

## 코딩 연습 (프로그래머스 시험은 연기됨)

실제 코딩테스트와 같은 배치(왼쪽 문제 · 오른쪽 solution.py 에디터 · 실행 결과 · 코드 실행 / 제출 후 채점하기)에서 68문제를 연습해요. 함수형/입출력형, 숨은 테스트 + 효율성 테스트, 코딩 모의시험(4문제 · 90분). 코드는 [Pyodide 0.26.4](https://pyodide.org)(Python 3.12)로 브라우저 안에서 실행돼요. Python(약 10MB)은 코딩 문제를 열 때만 내려받아요.

## 필기 문제 추가 · 수정

1. `src/written/chN.py`의 `QS`에 `MC(...)` · `SA(...)` · `ES(...)` · `FI(...)`를 추가 (비슷한 문제를 복사해서 고치는 게 가장 쉬워요).
2. `python src/written/bank.py --ch N` → `OK — 오류 없음`이 나올 때까지 고쳐요.
3. `python src/build.py` (코딩 문제 검증까지) 또는 `python src/build.py --quick` → `index.html`
4. `node tools/t_written.cjs` → 브라우저에서 전부 확인

`id`를 바꾸면 그 문제의 학생 기록(오답노트)이 끊기니 주의하세요.
